# Minecraft-AI-Skill

Skill Codex untuk membantu melanjutkan dan menyelesaikan proyek kode, web, server, Minecraft, serta tugas yang mengikuti spesifikasi.

Skill ini berfokus pada menjaga konteks dan koreksi terbaru, mempertahankan fitur yang tidak diminta untuk diubah, memeriksa hasil saat diminta, serta menyerahkan berkas dalam format yang diminta.

## Isi repo

```text
kolaborasi-proyek-pribadi/
├── README.md
└── SKILL.md
```

## Pasang di Codex

Salin folder `kolaborasi-proyek-pribadi` ke folder skill pribadi Codex:

- Windows: `%USERPROFILE%\.codex\skills\kolaborasi-proyek-pribadi\`
- macOS atau Linux: `~/.codex/skills/kolaborasi-proyek-pribadi/`

Pastikan `SKILL.md` berada langsung di dalam folder tersebut. Mulai ulang atau muat ulang Codex jika skill belum muncul.

## Gunakan

Panggil skill dengan `$kolaborasi-proyek-pribadi`, lalu tulis tugas yang ingin dikerjakan. Contoh:

```text
$kolaborasi-proyek-pribadi
Lanjutkan perbaikan situs ini. Cocokkan halaman dengan spesifikasi di PDF dan pertahankan fitur yang sudah berjalan.
```

Skill ini memberi panduan kerja; permintaan terbaru dan koreksi pengguna tetap menjadi acuan untuk setiap tugas.

## Sesuaikan

Instruksi skill ada di `SKILL.md`. Edit bagian yang ingin disesuaikan sebelum memasangnya, terutama jika preferensi atau jenis proyek berbeda.
